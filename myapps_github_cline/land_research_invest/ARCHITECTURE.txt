==============================================================
3. DATA FLOW (WORKFLOW)
==============================================================

  1. User sets criteria (config/criteria.yaml or UI)
  2. Agent calls: search_real_estate_portals + search_auctions
  3. For EACH parcel:
       geocoding_service       -> GPS coords from address
       zbgis_service           -> geometry (width, shape, area)
       distance_service        -> distance + drive time from BA
       flood_service           -> Q100 flood zone check
       terrain_service         -> slope, landslides, radon
       overpass_service        -> road, electricity, water, amenities
       bpej_service            -> soil protection class, fees
       price_analysis_service  -> EUR/m2 vs. local average, history
  4. scoring_service           -> weighted score 0-100
  5. If score >= 70:
       cadastral_service       -> manual LV checklist (B/C/D)
  6. notifier_service          -> email / Telegram alert


==============================================================
4. SCORING ALGORITHM
==============================================================

  Criterion             | Weight (default, configurable)
  ----------------------|--------
  Price (EUR/m2)        | 18 %
  Distance from BA      | 12 %
  Infrastructure        | 20 %
  Legal proxy           | 18 %
  Flood risk            | 10 %
  Soil quality (BPEJ)   |  8 %
  Terrain               |  7 %
  Protected zones       |  7 %

  >= 85 -> STRONG BUY   >= 70 -> INVESTIGATE
  >= 50 -> CONSIDER     <  50 -> SKIP

  Weights:    config/criteria.yaml -> scoring -> weights
  Thresholds: config/criteria.yaml -> scoring -> thresholds

==============================================================
8. AUTOMATION LEVELS
==============================================================

  AUTO   = agent handles fully, runs in parallel
  SEMI   = agent prepares 90%, you do 1 step (e.g. CAPTCHA)
  MANUAL = agent generates checklist/draft, you verify

  AUTO:   distance, flood, terrain, BPEJ, protected zones,
          infrastructure (OSM), soil, price analysis
  SEMI:   cadastral title LV (B/C/D) - CAPTCHA
          zoning plan (UP/UPI) - OCR + LLM
  MANUAL: transformer capacity (ZSDIS)
          archaeological zone (KPU)

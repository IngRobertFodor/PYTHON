SETTINGS - How to Customise Your Search
========================================

Everything is changed in ONE file:  config/criteria.yaml
After any change, just restart the app. No rebuild needed.


==============================================================
1. PRICE  (criteria -> price)
==============================================================
  max_eur: 50000             maximum price you will pay
  min_eur: 10000             ignore anything cheaper than this
  max_price_per_sqm_eur: 100 max price per square metre

  >> max_eur: 70000          raise budget to 70,000 EUR
  >> max_price_per_sqm_eur: 60  stricter price per m2


==============================================================
2. DISTANCE FROM BRATISLAVA  (criteria -> location)
==============================================================
  max_distance_km: 70

  >> max_distance_km: 50     tighter radius (50 km)
  >> center_lat / center_lon  change the centre point (e.g. Trnava)


==============================================================
3. PLOT SIZE  (criteria -> parcel)
==============================================================
  min_area_sqm: 600    minimum size in square metres
  max_area_sqm: 1500   maximum size
  min_width_m: 15      minimum width (building line requirement)

  >> min_area_sqm: 800   larger plots only


==============================================================
4. WHAT MATTERS MOST  (scoring -> weights)
==============================================================
!!! TOTAL MUST EQUAL 1.0 - if you raise one, lower another !!!

  price:            0.18   value for money
  distance:         0.12   distance from Bratislava
  infrastructure:   0.20   road, electricity, water access
  legal_proxy:      0.18   clean title (no liens, disputes)
  flood_risk:       0.10   not in flood zone
  soil_quality:     0.08   soil extraction cost
  terrain:          0.07   slope, landslide risk, radon
  protected_zones:  0.07   not in Natura2000 / national park
                   -----
  TOTAL:            1.00  <- must stay 1.00

  >> price is most critical:  price: 0.25, distance: 0.05
  >> legal safety first:      legal_proxy: 0.25, terrain: 0.00


==============================================================
5. SCORE RATINGS  (scoring -> thresholds)
==============================================================
  strong_buy:  85    top pick  - act quickly
  investigate: 70    good lead - verify and visit
  consider:    50    possible  - has some issues
                     below 50  = skip

  >> strong_buy: 90    be more selective


==============================================================
6. WHERE TO SEARCH  (sources -> enabled: true/false)
==============================================================
  nehnutelnosti_sk   ON    main portal
  topreality_sk      ON    major portal
  notarske_drazby    ON    notarial auctions
  spf                ON    state land (often cheap)
  obchodny_vestnik   ON    bankruptcy & court auctions  (!)
  exekutorske_drazby ON    enforcement sales            (!)
  drazby_net         ON    auction aggregator
  eks_statny_majetok ON    government property sales
  bsk_kraj           ON    Bratislava region surplus land
  obce_uradne_tabule ON    municipal land sales
  reality_sk         ON    major portal (careful mode)
  byty_sk            ON    property portal
  bazos_sk           OFF   classified ads (search blocked)
  bankove_drazby     OFF   bank auctions (check ToS first)
  facebook_mktplace  OFF   NEVER - prohibited by their rules

  (!) = best sources for underpriced land

  >> turn off a source:  sources -> NAME -> enabled: false


==============================================================
7. CHECKS TO RUN  (features -> true/false)
==============================================================
  All checks are ON by default. Turn off only if not needed.

  >> use_terrain: false         skip slope/landslide checks
  >> use_cadastral_semi: true   enable title check (needs 1 CAPTCHA click from you)
  >> use_notifications: true    get email/Telegram alerts


==============================================================
8. TERRAIN LIMITS  (criteria -> terrain)
==============================================================
  max_slope_percent: 15      steeper slopes raise building costs
  max_elevation_m: 400       higher = harder winters, worse access
  max_radon_risk_class: 2    radon level 1=low 2=medium 3=high

  >> max_slope_percent: 8    flat plots only


==============================================================
9. SOIL  (criteria -> soil)
==============================================================
  max_protection_class: 6
  Class 1-4 = high state fee to build on (can be thousands EUR/m2)
  Class 5-9 = low or no fee

  >> max_protection_class: 9   only plots with no extraction fee


==============================================================
QUICK REFERENCE
==============================================================
  Cheaper:        criteria -> price -> max_eur
  Closer/further: criteria -> location -> max_distance_km
  Bigger plots:   criteria -> parcel -> min_area_sqm
  Re-weight:      scoring -> weights  (must total 1.0)
  Score filter:   scoring -> thresholds -> strong_buy
  Turn off source: sources -> NAME -> enabled: false


  Validate your changes anytime:
    python -m pytest tests/test_config_validator.py -v

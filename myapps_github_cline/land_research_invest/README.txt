Land Research Invest
====================

An AI agent that searches for affordable building plots
(up to 70 km from Bratislava) and automatically checks them
against the criteria that matter most to you.

You set the budget and requirements. The agent does the research.
You get a ranked shortlist — and a checklist for the ones worth visiting.


==============================================================
WHAT THE AGENT CHECKS FOR YOU
==============================================================

For every plot it finds, the agent automatically verifies:

  Price          Is it priced fairly vs. similar plots nearby?
  Distance       How far from Bratislava? How long to drive?
  Flood risk     Is it in a flood zone? (100-year flood data)
  Terrain        How steep? Any landslide risk? Radon levels?
  Soil quality   Will building on it cost extra state fees?
  Road access    Is there a proper road? Wide enough for fire trucks?
  Utilities      How far to electricity, water, sewage?
  Environment    Near a motorway? Industrial area? Landfill?
  Protected land Not in a national park or Natura2000 zone?
  Plot shape     Wide enough and regular enough to build on?

Each plot gets a score from 0 to 100. The agent tells you:

  85-100   STRONG BUY  - excellent, act quickly
  70-84    INVESTIGATE - good match, go verify it
  50-69    CONSIDER    - possible, has some trade-offs
  0-49     SKIP        - does not meet your criteria


==============================================================
WHAT YOU STILL NEED TO DO MANUALLY
==============================================================

Some checks require your input — the agent prepares everything,
you just complete the final step:

  Title check (List vlastnictva)
    The land registry blocks automated access.
    The agent generates a ready-to-use checklist — you verify
    the actual record at:  https://kataster.skgeodesy.sk

  Zoning confirmation (UPI from municipality)
    You need written confirmation from the local council
    that the plot is zoned for family housing (IBV).
    The agent drafts the request letter for you.

  Electricity capacity
    The agent checks how close the power line is.
    You confirm actual transformer capacity with the distributor.


==============================================================
WHERE IT SEARCHES
==============================================================

  Real estate portals  (Nehnutelnosti.sk, TopReality.sk, Reality.sk)
  State land sales     (SPF - Slovak land fund)
  Notarial auctions    (often below market price)
  Court & enforcement sales  (can be significantly underpriced)
  Bankruptcy register  (Obchodny vestnik - gold mine for deals)
  Municipal land sales (local councils selling surplus plots)

Po kazdej zmene staci restartovat aplikaciu. Ziadna kompilacia.

Format YAML: odsadenie = medzery (NIE tabulatory).

CASTE CHYBY
==============================================================

  min > max:      min_eur musi byt mensie ako max_eur
  Zly YAML:       python -c "import yaml; yaml.safe_load(open('config/criteria.yaml'))"
  Zle prahy:      strong_buy > investigate > consider

  Overit po kazdej zmene:
    python -m pytest tests/test_config_validator.py -v
